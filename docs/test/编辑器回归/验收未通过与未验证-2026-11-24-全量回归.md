### F-01 行内 Markdown 下划线未触发

在空白正文逐键输入 `~omega~` 后单独按 Space。预期去掉定界符、为 `omega` 加下划线，空格保留在格式外。x2x 的正文仍是 `~omega~ `，DOM 无下划线标记。定向执行 `--grep ED-08-下划线`。 [ED-08 局部预期](./局部用例/05-富文本与段落排版.md#ed-08-行内-markdown) · [逐键证据脚本](../../../tests/editor/e2e/document-markdown.spec.ts)

### F-02 粗体、斜体和删除线提前转换

分别在新段逐键输入 `**alpha**`、`*beta*`、`~~gamma~~`，在闭合定界符后观察，再单独按 Space。预期 Space 后才消费定界符并应用格式。x2x 在最后一个定界符键入时已生成 `STRONG`、`EM`、`S`，三个子用例均重现。 [ED-08 局部预期](./局部用例/05-富文本与段落排版.md#ed-08-行内-markdown) · [逐键证据脚本](../../../tests/editor/e2e/document-markdown.spec.ts)

### F-03 H1 与 H9 从中间分段时丢失后段标题层级

在 H1 或 H9 中输入 `abc`，把光标移到 `a` 与 `b` 之间，按 Enter 后输入 `X`。预期得到两个同级标题 `a`、`Xbc`，相邻段 `Tail` 保持原样。x2x 保留前半标题，新行 `Xbc` 成为普通正文。两级标题均重现。 [ED-02](./局部用例/03-文字编辑与剪贴板.md#ed-02-分段与软换行) · [H1 与 H9 标题分段基线](../../editor/02-creation-and-editing/02-verification-matrix.md#h1-分段续测) · [浏览器复现](../../../tests/editor/e2e/document-text-editing.spec.ts)

### F-04 普通段尾的 Delete 未合并下一段

### F-05 引用内三段转正文、H1、H9 时解除原引用

在同一引用中建立 `111`、`222`、`333` 三段，从 `111` 的偏移 0 拖选到 `333` 的偏移 3。分别用 Mod+Alt+0、Mod+Alt+1、Mod+Alt+9 执行转换。预期三个结果保留同一个引用父级。x2x 的浏览器剪贴板结构显示三个目标块均已位于引用外，`blockquote` 数由 1 变为 0。复测用精确文本范围重现三格。 [ED-21](./局部用例/06-列表引用与块结构.md#ed-21-多块转换矩阵) · [浏览器复现](../../../tests/editor/e2e/document-conversion-matrix.spec.ts)

### F-06 引用内三段转列表时多出一个引用外空项

使用 F-05 的精确范围，分别按 Mod+Shift+7、Mod+Shift+8。预期原引用内只有三条相应的列表项。x2x 的三条原内容仍在引用内，复制出来的 HTML 在它们前面多一个引用外的同类型空项。两种列表均重现。 [ED-21](./局部用例/06-列表引用与块结构.md#ed-21-多块转换矩阵) · [浏览器复现](../../../tests/editor/e2e/document-conversion-matrix.spec.ts)

### F-07 引用内三段再次选择引用时未解包
