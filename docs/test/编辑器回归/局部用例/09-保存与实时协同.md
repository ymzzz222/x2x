## SY-01 自动保存与回读

**初态与操作**

A 连续键入两次，观察待保存、回执和云端已保存。用另一个全新登录会话打开。

**预期**

待回执时显示真实状态，独立会话读到最后一次编辑与正确标题。

## SY-02 并发合并

**初态与操作**

A、B 各自的 Chrome 会话打开同一篇，同时在异段与同段插入两个唯一标记，再并发移动或编辑有层级的块。

**预期**

两端最终收敛且各改动只出现一次。结构未损坏，刷新与第三独立会话读回一致。

## SY-03 真实 Realtime

**初态与操作**

A、B 打开同篇，检查实际私有频道就绪。观察两人名单及光标，分别键入、移动、离开并重进。

**预期**

真实通道承载保存和光标更新，用户、位置、在线数准确。光标不计入正文或历史，离开后清除。

## SY-04 HTTP 回退

**初态与操作**

两端在线时只断 B 的文档 WebSocket，保持 HTTP。A 写入新标记，B 等待并读回，再恢复通道。

**预期**

名单和旧远端光标清除或降级，B 通过 HTTP 读到新标记，恢复后实时通道可用。

## SY-05 公开双会话

**初态与操作**

先完成 `EN-05`。两位匿名访客打开同一篇，各写一段不同文字并查看在线名单。

**预期**

映射同一专用文档身份，保持独立在线会话，显示两位在线。双方可见对方正文，独立重开能读回。

## SY-06 丢回执与重试

**初态与操作**

指定保存请求已落库但应答中断。等待重试，记录相同批次键及提交序号。补实际 503 和「重试」操作。

**预期**

提示与实际状态一致，重试不重复落库，最终进入已保存，独立读回完整。

## SY-07 离线和重连

**初态与操作**

B 在已打开的文档断网，继续输入，再联网。A 同时写入另一段。另测断网编辑后关闭该页，恢复网络再打开。

**预期**

离线待提交保留在本机，状态准确。联网后自动合并并保存，回读无遗漏或重复。

## SY-08 迟到应答与切文档

**初态与操作**

延迟 A 的一次保存响应，在响应到达前补一次编辑并切到另一篇继续输入，再返回。

**预期**

响应只作用于原文档和批次，不会提前显示最新文本已保存或污染另一篇。

## SY-09 离线撤权及旧频道

**初态与操作**

B 离线写入后由 A 撤权或降为只读。B 恢复网络，检查待提交、旧光标、旧链接和两会话回读。

**预期**

旧角色无法继续提交或收到新正文，未同步草稿保留在本机并提示。云端正文保持授权用户的版本。

## SY-10 本机存储故障

**初态与操作**

在隔离会话阻断编辑持久化存储后打开、键入及重新打开已有正文。

**预期**

依当前产品规则显示安全的只读或错误状态。云端保持原有正文，避免以空内容覆盖。

需要触发受控网络条件的场景应同时核对被拦截的请求和恢复后的业务结果。
