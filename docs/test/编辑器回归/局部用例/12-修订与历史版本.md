## CO-06 修订接受

**初态与操作**

C 对选区提出替换建议，B 查看差异并接受。刷新两端，尝试重复接受。

**预期**

只有有权角色可接受，替换一次且限于目标范围，原建议状态保持。

## CO-07 修订其他分支

**初态与操作**

提出第二条建议，回复、改写或撤回；另建一条由 B 拒绝。补目标先被编辑或删除再处理。

**预期**

建议生命周期可追踪，撤回／拒绝保留原文，失效目标不会误改其它文本。

## CO-08 历史与命名版本

**初态与操作**

A 保存命名版本，再修改。打开版本、比较正文、复制版本链接，由 C 打开并核对作者、时间和只读。

**预期**

指向正确快照，版本与当前状态可区分，权限外角色无法查看。

## CO-09 还原与旧代次

**初态与操作**

形成两个命名版本，B 持旧离线草稿。A 还原前一版本，再让 B 联网。

**预期**

当前正文备份并切换版本，旧草稿不混入已还原版本，新编辑可以继续保存。

版本用例先建同一文档的两个命名快照，每个快照使用不同的正文标记。修订用例先分别确认建议者和采纳者可使用的动作。
