## ED-05 键入井号后按空格创建一级标题

1. 打开有单独页标题 `X2X-QA`、正文仅一空段的编辑文档。点击空正文，确认光标位于正文段。
2. 只键入一个半角 `#`。此时可见 `#`，该段仍是普通正文。
3. 单独按一次 `Space`。同段立即具有一级标题语义，正文消费井号和空格，光标留在空一级标题内，页标题保持 `X2X-QA`。可用正文内的 `data-heading-level="1"` 核对级别。
4. 键入 `1`。应得到一个文本正好为 `1` 的一级标题。等「云端已保存」，用新会话打开，核对相同级别、文字和页标题。
5. 在新普通段键入 `a`、`#`、`Space`。仍为正文 `a# `。另开空段仅键入井号，单独检查未按空格时的普通段状态。 [飞书 Markdown 参考](https://www.feishu.cn/hc/zh-CN/articles/118804574721)

## ED-06 H2–H9

**初态与操作**

在各段开始分别逐键键入 2 至 9 个半角 `#`，每级先校验仍是普通段，再按 Space 并键入级别数字。按 [ED-05](#ed-05-键入井号后按空格创建一级标题) 复查独立读回。

**预期**

空格触发对应级别，前缀被消费并可直接续写。H7–H9 具备各自的标题级别，目录和读回一致。

| 子用例 | 空段逐键输入 | Space 后的正文级别及续写 |
| --- | --- | --- |
| ED-06-H2 | `##`，再按 Space | 级别 2，空标题内继续键入 `2` |
| ED-06-H3 | `###`，再按 Space | 级别 3，空标题内继续键入 `3` |
| ED-06-H4 | `####`，再按 Space | 级别 4，空标题内继续键入 `4` |
| ED-06-H5 | `#####`，再按 Space | 级别 5，空标题内继续键入 `5` |
| ED-06-H6 | `######`，再按 Space | 级别 6，空标题内继续键入 `6` |
| ED-06-H7 | `#######`，再按 Space | 级别 7，空标题内继续键入 `7` |
| ED-06-H8 | `########`，再按 Space | 级别 8，空标题内继续键入 `8` |
| ED-06-H9 | `#########`，再按 Space | 级别 9，空标题内继续键入 `9` |

每格在 Space 前检查普通段原串，转换后检查光标、正文标题级别与页标题。飞书的输入规则、各级创建和标题内编辑分别有实际观察记录。 [S02 验收矩阵](../../../editor/02-creation-and-editing/02-verification-matrix.md) · [S02 标题编辑](../../../editor/02-creation-and-editing/02-heading-editing.md)

## ED-07 Markdown 列表和引用

**初态与操作**

每次从空段开始，逐键输入对应前缀。检查普通段显示前缀后，单独按 Space，再键入样本文字。列表项用两次 Enter 验证继续与退出。引用在内容尾分段，随后从空末段退出。

**预期**

生成对应的无序项、有序项或引用，光标可在内部续写。列表按 Enter 继续，空项再次 Enter 退出到正文。

| 子用例 | 前缀与文字 | 可观察结果 |
| --- | --- | --- |
| ED-07-无序减号 | `-`、Space、`1` | 无序列表第一项 `1`，Enter 新建第二项，空项再按 Enter 回正文。 |
| ED-07-无序星号 | `*`、Space、`1` | 同样建立无序列表，列表续写及退出后的光标可用。 |
| ED-07-有序 | `1.`、Space、`1` | 标记与正文分开，Enter 创建下一编号，空项再按 Enter 退出。 |
| ED-07-引用 | `>`、Space、`3` | 首次 Enter 在引用内新增空段。再次 Enter 后继续键入 `4`，`3` 仍在引用内，`4` 在正文。 |

## ED-09 行首加号

**初态与操作**

分别在唯一空段、仅空格段和已有正文末空段打开行首「+」。选择标题和引用，再各做一次 Esc。

**预期**

空段可在当前行变为目标类型。取消行为符合对应初态，原文、光标及历史保持可用。

## ED-10 斜杠插入

**初态与操作**

在空段键入 `/`，查看一级标题、列表、引用等。用鼠标点一级标题，在另一段用关键字和方向键＋Enter 选列表。试无搜索结果及 Esc。

**预期**

同类菜单正确过滤、消费触发文本并恢复焦点。取消或无结果时原操作可继续，目标块之外的文本保持。

## ED-11 块菜单与浮动工具栏

**初态与操作**

分别聚焦一段、选择段内文字、选择跨块范围，观察句柄和浮动条。用鼠标、Tab、方向键和 Escape 进入并退出子菜单。

**预期**

菜单按选区状态对外可用，键盘可操作，菜单关闭后回到原入口或选区，动作作用于相应块或选区。

## ED-18 标题编号

**初态与操作**

对 H1、H9 和混合父子标题开关编号，从有序项切成编号标题，再降低父项或另起编号。

**预期**

正文、目录、整块复制的编号一致。用户选择的起号和未选后代保留，编号独立于可编辑文本。
