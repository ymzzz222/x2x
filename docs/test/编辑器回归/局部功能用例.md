# x2x 编辑器局部功能用例

环境、角色、样本和执行顺序见[整体验收](./整体验收.md)。默认使用新建的临时文档，A 为所有者，B 为编辑者，C 为阅读者，D 无访问权限。每项用例从指定初态开始。重复输入、类型或角色时重建初态，结论可用编号加后缀指向具体级别、入口或角色，例如 `ED-06-H9`。

键位中的 `Mod` 在 macOS 为 Command，在 Windows 为 Ctrl。键入类用例按实际键序触发，剪贴板用例通过浏览器正常复制、剪切和粘贴。每组结束后重建样本或清理本组创建的文档、链接和会话。
