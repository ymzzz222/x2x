## 正文、页标题和容器限制

正文样例与页标题分别验收。非空标题五键及历史见C01-001；空标题六键、非空标题引用、标题全文选择/块首斜杠见C01-002，不把正文转换能力套到页标题。

引用在 DOM 中是 quote_container 加内部块。将引用作为来源时，须声明内部块类型；本表引用来源为单个普通 text，不能替代含标题、列表或多段引用的全部状态。

三段引用中仅转换中间 text 时保留原引用；块菜单取消该段引用则拆成前引用、中正文、后引用，见 REQ-S03-C06-003。标题后续内容样例为展开同父块，不能凭 DOM 平级关系断言折叠大纲归属。

## 属性与状态边界

- 标题“有序列表”命令保留标题并增加编号；有序项转标题会带编号，不能丢掉这个来源差异。
- 同类型标题/列表命令切回正文；普通正文命令无变化；重复引用移除或拆分容器，按选区与容器范围判定。
- 空块、首中尾、部分文字与全部文字反向选区只有代表映射双轮，详见主文档 C04 条目，不扩报为全矩阵状态覆盖。
- 红字黄底、四项行内格式、链接及居中只有正文来源的抽样目标双轮；右对齐接续已用块菜单设置并核对实际样式，再完成有效双轮，见格式文档 C05-002；旧输入异常窗口保留。
- 缩进菜单对当前唯一右对齐正文提示“无法缩进当前内容块”，两轮含通知 DOM；不把它推广为所有正文都不支持缩进。
- 成功缩进有序子项转 H1/H9/正文/无序各两轮，保留实际 parentBlock 与原块身份；文字区因标记变化而位移，见格式文档 C05-004/005。
- 折叠 H1→正文已补两次有效窗口，撤销恢复 H1 时后续内容保持展开，见主文档 C06-005。
- 保存提示只是 UI 观测；H1、嵌套H9及两类列表/引用均已补目标代表转换的双轮 Chrome 刷新和夸克独立读取，见主文档C07-002/008/011；不声称每个入口及属性组合都独立重载。

全部 I 单元均为“推断（sir 已授权抽样）”。M 单元的必要DOM、重复条件、身份和历史已审计；入口、状态、属性、容器及重载按各自代表条目验收，不能将M扩报为所有状态均实测。
