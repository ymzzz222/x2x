# 文档编辑器需求范围

首期交付 **文字文档的阅读与编辑**、**协同、分享与权限**。正文插入、嵌入和扩展能力排在首期之后，优先级最低。

## 首期 · 文字文档的阅读与编辑

| 功能 | 需求 |
| --- | --- |
| 正文滚动 | 支持在长文档中连续上下滚动，阅读和编辑时均可浏览正文。 |
| 目录与章节 | 根据多级标题生成目录，点击目录跳转到对应章节，支持展开和折叠章节。 |
| 内容定位 | 复制标题或内容块的锚点链接，打开后定位到对应内容。 |
| 查找与替换 | 在当前文档中查找文字、切换匹配项、替换当前匹配或全部匹配。 |
| 阅读视图 | 支持阅读和编辑模式切换，设置默认、较宽或全宽布局，支持移动端横屏阅读。 |
| 文档演示 | 支持全屏连续滚动和分页演示、显示或隐藏评论、继续上次演示。 |
| 基础文字编辑 | 支持输入、选择、删除、换行、剪切、复制、粘贴、撤销和重做。 |
| 富文本格式 | 支持粗体、斜体、下划线、删除线、行内代码、文字色和背景色。 |
| 段落排版 | 支持正文与多级标题、对齐和缩进、有序与无序列表、引用、高亮、分割线和分栏。 |
| 内容块编辑 | 支持选中内容块、拖动排序、剪切、复制、删除和转换类型，以及整体移动折叠章节。 |
| 编辑入口与快捷操作 | 支持工具栏、选区浮动工具栏、行首 `+`、`/` 命令、块菜单、快捷键和 Markdown 语法。入口只列出首期可用能力。 |
| 文档外观 | 支持文档标题、标题图标、封面和文档信息显隐。 |

## 首期 · 协同、分享与权限

| 功能 | 需求 |
| --- | --- |
| 实时协同 | 多人可同时阅读或编辑同一篇文档，实时同步内容，显示在线协作者。 |
| 自动保存与离线 | 编辑自动保存。支持离线时保留改动，恢复网络后同步到云端。 |
| 提及 | 在正文或评论中用 `@` 提及协作者并发送通知，支持引用可访问的文档。 |
| 评论与互动 | 支持全文、选区和内容块评论，以及私有评论、回复、表情回应、分享单条评论、解决与恢复、文档点赞。 |
| 修订 | 支持建议式编辑，展示修订差异，允许回复、修改或撤回建议。有编辑权限的人可逐条接受或拒绝。 |
| 关注与通知 | 关注正文更新或评论，收到提及、回复、修订和权限变更等通知后，可从通知定位相关内容。 |
| 历史与版本 | 查看修改人、时间和变化，支持还原历史，以及保存、命名和分享版本。 |
| 分享 | 邀请个人、群组、部门或用户组，复制并分享链接，按策略设置组织内或对外访问、访问密码及停止分享。 |
| 权限管理 | 管理阅读、编辑和管理角色，申请、授予或撤回权限，处理继承和所有权转移，细分评论、复制、打印、下载与创建副本等权限。 |
| 企业数据保护 | 支持文档密级、降级审批、水印、对外分享策略、默认权限与批量权限筛查。 |
| 文档信息与统计 | 展示创建者、所有者、更新时间、字数及权限范围内的访问、点赞、评论和操作记录。 |
| 会议文档协作 | 会议共享文档时支持跟随共享人滚动、自由浏览和重新跟随，以及会中评论、编辑和标注。 |

### 首期验收场景

- 长文档可连续滚动，可通过目录、锚点和搜索结果定位。撤销正文或格式修改后可恢复到修改前的状态。
- 两位编辑者同时打开同一篇文档时可互相看到改动。刷新后可查看已保存内容，离线修改在恢复网络后可同步。
- 阅读者能按权限阅读和评论，编辑者能修改正文和处理修订，管理者能变更权限。停止分享或撤回权限后，原链接按更新后的权限判断访问。
- 评论可定位到原内容并解决或恢复，修订可逐条处理，历史版本可按权限查看或还原。
- 会议共享中可在跟随与自由浏览之间切换，重新跟随后定位到共享人当前看到的内容。

## 后续迭代 · 最低优先级

| 功能 | 需求 |
| --- | --- |
| **表格** | 单项管理文档内普通表格、嵌入电子表格及数据引用。表格内滚动、表头、单元格、行列、合并拆分、尺寸、样式、公式、筛选排序和图表等操作统一归在此项，具体能力按表格类型区分。 |
| 图片 | 正文图片插入、预览和编辑，以及评论附图和图片区域评论。 |
| 音视频与附件 | 上传、嵌入、播放和预览文件、音视频及会议记录。 |
| 代码块与数学公式 | 代码块语言和语法高亮，以及 LaTeX 数学公式。 |
| 同步块 | 在同一篇或不同文档间复用内容并同步更新。 |
| 画板和图形 | 画板、流程图、UML、思维导图等。 |
| 链接卡片与引用关系 | 普通超链接、网页卡片、双向链接和文档关系图。 |
| 任务与互动组件 | 任务、日期提醒、日程卡片、倒计时、投票、问卷和信息收集。 |
| 应用嵌入与小组件 | 按钮、第三方内容嵌入、目录/时间轴等小组件。 |
| 翻译、词典与 AI | 文档和评论翻译、词条释义、AI 速览、问答及写作辅助。 |
