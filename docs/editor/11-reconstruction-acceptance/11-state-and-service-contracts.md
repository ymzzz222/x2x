# S11 状态、结构及服务验收合同

日期：2026-10-27。本页把可观察规则、当前源码与项目验收要求分列。
它不补造飞书内部Schema、服务端状态机、消息时序或幂等协议。
各状态可同时存在，例如离线＋待保存＋失焦；下表不是互斥枚举。
未取得运行证据的转移保持未验证，不用箭头或源码入口代替实测。

## 1 编辑与历史状态

| 状态/转移 | 证据已支持的范围 | 项目验收断言与未验证边界 |
| --- | --- | --- |
| 加载中→已加载 | S01真实刷新由无根到已连接空根；S02/S10有内容重载另验 | 无根/未同步不当作真实空文档；不得覆盖已有服务内容。缓存空/旧/损坏矩阵未验证 |
| 已编辑→有效落点 | 首字符、转换、删除恢复各有精确文字/空叶/块选择 | 命令接收者、范围和范围外内容逐步核对；有效落点不能仅看activeElement |
| 聚焦→失焦→返回 | S01 Cmd+L仍可保留Range；S02 DevTools往返可恢复插入点 | 真实焦点与保留Range分开；切文档、长失焦和异步晚回调不得沿过期范围写入 |
| 普通输入→组合→提交 | S02/S09真实组合及历史有代表证据；H1/H9快捷键结果不同 | 以实际isComposing/事件链判断；临时拼音不是最终正文。输入源品牌、非可信compositionend和未测入口保留 |
| 编辑→阅读→编辑 | S01/S09主动阅读可见CE切换、按键不写正文、再恢复编辑 | 这是用户视图切换，不替代真实降权、已有历史栈与服务端拒绝 |
| 可写→真实只读→可写 | 只有已有只读页快捷键门禁；带旧历史的真实权限切换未验证 | 同一会话持有可撤销内容后降权，测试键盘/菜单/暴露命令/真实beforeinput，恢复后继续编辑 |
| AI开始→锁定→完成/失败 | 当前源码有锁与setEditable入口；没有真实测试任务验收 | 预览不能作为正式落版；普通锁不得任意重建Y.Doc；完成、断连、取消和失败的解锁按真实服务核对 |
| 普通编辑→修订→接受/拒绝 | S10有指定新增、删除、格式、分段与转换建议双轮 | 标记、文字、卡片、范围和历史分别比较；H9/全部属性、跨块和并发建议未全覆盖 |
| 新编辑→Undo/Redo→分支 | S09逐步比较中间态、Redo失效和远端隔离代表窗口 | 焦点/重选/采样/节奏是前置；不从约3秒双轮推定通用合并阈值 |
| 展开→折叠→历史 | S06 H1/H9折叠各有Undo展开、Redo折叠、再次Undo双轮 | 当前项目fold meta显式addToHistory=false为对齐项；目录折叠与正文折叠不能共用结果 |

## 2 保存、恢复与会话状态

| 转移 | 必须观察与比较 | 不能替代的证据 |
| --- | --- | --- |
| 未修改→本地变更 | 文档/实例身份、原基线、当前变更代次与待保存内容 | wordChanged/needSave布尔值不能单独证明保存版本归属 |
| 待保存→请求中 | 捕获本次请求对应文档及内容，发出后允许继续编辑的范围 | 请求存在、网络在线或提示变化不是持久化确认 |
| 请求中→确认 | 明确确认的内容版本；独立读回文字/结构/属性/元数据 | 旧A确认不得清除新B脏状态；响应抵达顺序不自动等于编辑顺序 |
| 请求中→失败/离线 | 保留待确认内容与可诊断错误，恢复服务后可重试/继续 | navigator.onLine和缓存DOM不证明服务端可写；重试不得重复正文 |
| 离线→恢复网络 | 比较离线编辑、最终独立读回和历史，确认未发生部分丢失 | S10受控离线刷新仅R2，不补成两轮受控确认；TailE风险接受只限研究载荷 |
| 当前文档→另一文档 | 旧实例、监听、请求、provider/Y.Doc与缓存房间分别清理/隔离 | 旧确认不得回写新文档版本、提示、焦点、历史或正文 |
| 历史预览→提交恢复 | 指定版本/请求标识、明确成功或失败、会话重建及独立读回 | 预览DOM、请求已发送或超时兜底提示不证明恢复成功 |
| 旧数据→迁移→再次打开 | 来源版本/哈希、文字/格式/结构/业务字段逐项对照；重复执行无重复 | 源码有migrate与schemaVersion不证明实际样本兼容或可逆 |
| 升级失败→回退 | 保留原件/确认版本，实际恢复数据与兼容协议，并继续编辑保存 | 仅切回前端包不是数据和协议回退通过 |

SR01保存响应、SR02替换门禁、SR03人物版本恢复兜底与SR04外部引用标题条件均见[源码对照](./11-project-contract-comparison.md)。
SR05标题转正文的隔离函数验证已确认遗漏后代，按BG08阻断发布；没有完整UI/协同复验，不把该证据扩报为整条生产流程复现。
SR06实际键盘扩展配置缺少自身命令注册；SR07同级标题菜单源码路径与原型不同。两者关联BG05，不把仅配置加载当作完整Editor验收。
当前没有足够服务运行证据判上述生产转移全部通过。

## 3 结构与属性的可用规则

| 对象 | 已确认规则/当前来源 | 约束 |
| --- | --- | --- |
| 正文与标题壳 | 飞书两个编辑区；项目doc→myPage→header＋children | 不把PM结构名当作飞书内部模型；输出DOM和业务结构分别验 |
| 标题级别与编号 | H1…H9；编号是附加属性，独立不可编辑marker | 有序目标命令在标题上可保留标题并编号，不能统一转列表 |
| 引用 | 容器内可有text/标题/列表代表结构；部分操作可拆包装 | 合法代表不等于任意嵌套均合法；外部粘贴与内部转换分开 |
| 真实列表深度 | S05已有无固定上限决定；当前项目4层常量需对齐 | 十五层是探查下界；无合法前项不能加深不构成硬上限 |
| 首行/块缩进 | 飞书text-indent、结构父级与项目块margin/indent分开 | 当前块缩进0–8不是列表祖先上限；只按实测前置验菜单/Tab差异 |
| 空态与软行 | 空叶占位非用户文字；同块ace-line与硬分段分别核对 | 不把所有零宽字符都删掉；视觉行与BR数量不单独判语义 |
| 身份 | 同会话对象、页面block ID和逻辑record ID分别记录 | Redo/删除恢复可新建DOM；跨加载不比较WeakMap引用 |
| 行内属性 | 显式bold/link/color与块默认字重/字号分开 | S02新输入9恢复默认但旧bold保留，不能整体重置达到表象 |
| 粘贴长度 | 已批准项目plain单次100000/全文配置460000 | plain拦截当前用UTF-16字符串length；全文计数须按实际限制插件分别核对，不能自动统一单位 |
| 字号/行高 | S03正文16/400/26、H1 26/500/36.4、H9 16/500/22.4 | 这些是代表样式观察，不能作为所有平台统一视觉容差 |

精确状态仍须回到[169格索引](./11-conversion-index.json)和原用例；这些表格没有扩大全组合实测范围。

## 5 性能、视觉与支持范围的冻结表

| 项目 | 当前值/证据 | 冻结前必须补齐 |
| --- | --- | --- |
| 输入、命令、菜单、独立可见保存延迟 | 无生产分布；S01只有首rAF有效输入各组2样本 | 明确计时起止、固定环境/数据规模/监控开关、样本数与分位，再由sir确认目标 |
| 长文/上限/复杂嵌套 | 120段是功能样例，深层是结构探查 | 普通/长文/项目边界规模的分布、拒绝前部分写入与可恢复性 |
| 内存、连接和监听趋势 | 有清理入口，没有长时资源验收 | 重进/切换/重连固定次数与时长，资源趋势、一次性缓存和持续增长区分 |
| 字体、布局与菜单定位 | 代表样式有基线；400px Desktop-UA面板有−23.125px左溢出双轮 | 项目固定字体、字号/行高/间距/标记/引用/菜单热区实测与可操作容差；不能默认接受裁切 |
| 阅读器与浏览器 | 当前Word XML与LibreOffice渲染编号不同，Microsoft Word未验；研究Chrome/辅助夸克各有范围 | 明确目标阅读器/浏览器/辅助技术及版本后验收，不扩张支持声明 |
| 回退与未确认编辑保障 | 无真实回退运行或冻结的保障范围 | 数据/协议备份与恢复试验，区分已确认/未确认载荷，并取得明确限制决定 |

sir于本批明确回复“暂无标准，保持待收口”；这些未定值不填“流畅”“差不多”或任意毫秒/像素阈值。
sir随后明确接受S11研究包交付完成；最终需求仍待收口，以上未定标准未获豁免。项目发布门禁单独遵循[BG01–BG08](./11-conflicts-and-release-gates.md)。

## 6 最终冻结所需的具体输入

| 未决项 | 已有资料可确定什么 | 完成最终收口必须取得什么 |
| --- | --- | --- |
| 支持环境 | 研究主端Chrome、辅助夸克；package browserslist只是构建目标 | sir明确项目浏览器/系统及版本、Word/PDF阅读器、辅助技术支持范围；不拿构建目标当验证通过范围 |

| 视觉与可操作性 | 固定字号/行高、菜单矩形及窄面板溢出有证据 | 项目样例下的字体/布局基准和可操作容差；不能直接采用原型裁切或任意像素数 |
| 保存确认协议 | 客户端传id/version/content，有失败重试及空保存守卫 | 服务响应对应哪版内容、旧响应处理、冲突/重复/超时与切文档策略；受控回执和独立读回 |
| 离线与未确认编辑 | 已确认内容必须可恢复；S10只模拟标签离线 | 未确认载荷保存位置、可恢复期限、关闭/重开/清缓存后的保障及失败提示，不能自行承诺不丢 |
| 权限与AI | 前端组合锁与provider事件名可定位 | 带可用旧历史的真实权限切换/AI任务环境，实际拒绝、完成/取消、重连与解锁后历史 |
| 迁移与回退 | 当前迁移入口、字段及版本写入路径已定位 | 授权旧样本及哈希、兼容版本、数据/协议回退方案与实际恢复后的再次编辑保存 |
| 新发现对齐项 | 首次全选、折叠历史、列表深度及命名按现有目标有差异 | 默认沿1:1与已批准保护合同对齐；若保留当前首次全选等差异，需明确的新差异决定 |

这些是有限、可交接的输入清单，不通过继续增加近似静态检查来替代。
未取得输入时，可交付本阶段研究包；不能声称“最终规范已冻结”或“项目可发布”。
