# S12 飞书云文档多块选择与转换需求

实测日期为 2026-11-26，北京时间。使用 macOS 26.5、Chrome 158.0.8127.37 和一篇新建的飞书测试草稿。通过前台鼠标拖选、实际键盘和产品菜单操作。每次先看真实选区，再核对块类型、顺序、编号、父级和格式。代表用例补测撤销、重做和刷新。草稿的合成内容已清空并刷新确认。

本章补充 S04 的同类与混合来源矩阵及 S05 的嵌套规则，新增对 H2–H8、任务、代码块、高亮块、同步块、表格选区的前台观察。x2x 实施范围以项目需求为准。 [S04 原运行矩阵](../04-multi-block-conversion/04-verification-matrix.md) · [S05 嵌套矩阵](../05-nesting-and-combinations/05-verification-matrix.md) · [x2x 需求范围](../文档编辑器需求范围.md)

同日另补测了两块、三块及更多块的来源顺序。六类来源转 H2 的两块 36 种、三块 216 种已逐组执行，四至十二块补测 48 组。另选 16 种来源顺序分别转有序列表和引用。 [顺序矩阵与复跑规则](./12-多块来源顺序矩阵.md)

## 1. 范围计算

### REQ-S12-01 多块文字选区按完整块转换

在同一文档中，首尾只选中部分文字时，选中的逻辑块整块转换。普通块端点位于下一块的文字偏移 0 时，下一块保留原类型。正向和反向均按相同的首尾边界计算。转换前后的正文字符与顺序保持。普通转换后仍可读到原来的文字端点偏移。部分入口会交换锚点与焦点，方向是否保留按命令和入口验证。

被选块以外的内容只受明确的派生规则影响。例 A 的终点移到 `E5eee:0` 后转 H2，两种拖选方向均保留该块的有序项类型与文字。它原先显示 8，前一有序项转成标题后显示 1。用例应同时核对块类型和当前编号。 [S04 选区边界](../04-multi-block-conversion/04-selection-boundaries.md)

### REQ-S12-02 文字选区与整块选择

在正文中连续两次按 ⌘A，第二次进入正文整块选择。例 A 的两个护栏段、全部普通块和引用子段都参与转 H2。页标题保持原样，已有引用容器保留。例 C 的整块全选还会纳入末尾空段。当前选区只有头尾半选的文字拖选时，范围之外的空段保持原样。

键盘扩选沿实际选区计算。例 C 中光标位于 `First:1` 时按两次 Shift+↓，实际范围为 `First:1 → WordSoft:1`。转 H9 后，两个端点所在块与中间空块均为 H9，后面的有序项保持起号 12。

### REQ-S12-03 跨容器时读取实际选区

例 A 从 `A1aaa:1` 拖到已有引用的第一段 `Q6quote:3`，飞书实际选区扩到整段共同引用，包含 `Q7quote`。反向拖选得到相同覆盖。落点设为 `Q6quote:0` 时也观察到整个引用入选。两种方向转 H2 时，引用内两段变成 H2，继续留在原引用里。

把这个跨引用范围转为引用时，外部已选块进入一个新增的共同引用，已有引用与其成员保留，两个容器并列。例 B 在同一三段引用内只半选前两段后再选「引用」，前两段解包，第三段继续留在引用中。相同范围转无序列表时，前两段在原引用内部变成无序项，第三段保持正文。外部跨界和容器内部半选使用各自观察到的范围。

## 2. 转换目标

### REQ-S12-04 混合块到 17 个目标

例 A 对五个逻辑块执行正向和反向半选，各目标形成两组有效执行，共 34 格。表中「列表父项」与「子项」分别是 `C3ccc` 与 `Kid4`。普通类型及包裹型目标保持五块完整文字，粗体样本为 `A1aaa` 中的 `1`。原有引用及两端护栏均保留。各格执行一次撤销、一次重做并再次撤销，核对正文、类型、编号和父级。

| 目标 | 使用入口 | 例 A 结果 |
| --- | --- | --- |
| 正文 | 选区工具栏 | 五块均为正文。子段仍挂在原父块下。 |
| H1、H2、H3 | 选区工具栏 | 五块均为目标级别。原 H1 和普通段无编号，后面三块按 1、2、3 显示编号。子段保留父级。 |
| H4、H5、H6、H7、H8、H9 | ⌘⌥ 加相应数字。另用「其他标题」菜单核对 H4。 | 六级分别执行，结构和编号规则与前三个标题级别一致。 |
| 有序列表 | 选区工具栏 | 原 H1 变成编号 H1，编号为 1。其余四块为有序项，顶层三项按 1、2、3 显示，子项保持缩进。 |
| 无序列表 | 选区工具栏 | 五块变成无序项，保留子项父级。 |
| 任务 | 选区工具栏 | 五块变成任务，保留子项父级。 |
| 代码块 | 选区工具栏 | 分别形成五个代码块，子项提升到顶层。正向复核五段完整代码文字与原块的当次界面身份。转换后原文字范围收起。 |
| 引用 | 选区工具栏 | 一个新增引用容器包住五块，保留原类型与子项归属。移入的顶层列表编号从 1、2 开始。 |
| 高亮块 | 选区工具栏 | 一个高亮容器包住五块，保留原类型与子项归属。移入的顶层列表编号为 1、2。 |
| 同步块 | 选区工具栏 | 一个同步块源包住五块，保留原类型与子项归属。移入的顶层列表编号为 1、2。 |

基础同类切换按 S04 的同类矩阵回归。例 A 是混合来源，部分块原先已经是目标类型。以转 H1 和转有序为例，应按混合矩阵输出，避免把整组当成同类切换。 [S04 同类来源矩阵](../04-multi-block-conversion/04-homogeneous-matrix.md)

### REQ-S12-05 保留边界文字、格式与编号关系

文字范围的首尾半选只决定目标块。转换后每个目标块仍含全部原文字。例 A 的 `A1aaa` 和 `E5eee` 在半选后仍是完整块。正文、标题、列表、任务及包裹型代表目标保留了 `A1aaa` 中的粗体 `1`。例 C 的 `Word` 与 `Soft` 通过真实 Shift+Enter 处于同一逻辑块，转 H2 后保留同块内换行。

显式起号被转换或移动到新的编号组时，按目标组重算。例 A 的 7、8 移入新引用、高亮或同步源后显示 1、2。例 C 仅转换前面的块时，外部的 `NumTail` 保留 12。连同 `NumTail` 全选转 H2 时，它显示编号 1。撤销需恢复原类型、原归属和原可见编号。

## 3. 特殊边界

### REQ-S12-06 折叠标题与隐藏后代

例 D 中折叠 `FoldHead`，界面暂不渲染两块后代。转换应区分只到父标题文字的选区与跨过整段折叠范围的选区。

| 测试范围 | 转无序列表后的实际结果 |
| --- | --- |
| `LGuard:2 ↔ FoldHead:4` | 两个端点所在块变成无序项。展开后代，保留后代原来的 H2 和正文类型。正向用菜单，反向用 ⌘⇧8。 |
| `LGuard:2 ↔ NextHead:0` | `LGuard`、`FoldHead` 和两块隐藏后代变成无序项，`NextHead` 保持 H1。两方向均实测。 |
| `LGuard:2 → NextHead:2` | 隐藏后代与 `NextHead` 均变成无序项，后面的 `Outside` 保持正文。 |

撤销恢复原有标题和后代类型，当前视图呈展开。跨折叠的三次执行均核对了重做。在后续表格保存刷新时，同一草稿重新显示折叠，手动展开读回原后代。历史操作后的可见状态和重新打开后的折叠状态需要分别断言。

### REQ-S12-07 文档内表格的外部、文字和整格边界

在例 D 的 `RGuard` 后通过斜杠菜单插入 2×3 普通表格，第一行前两格填入 `CellLeft`、`CellRight`。

| 实际选择形态 | 命令 | 观察结果 |
| --- | --- | --- |
| 正文跨入表格，拖到 `CellLeft:4`，正向与反向 | H2 | 选区文字含两格内容。仅外面的 `RGuard` 成为 H2，表格及两格内类型保持。 |
| 同一外部跨表格范围 | 引用 | 仅外部 `RGuard` 进入引用，表格继续作为相邻顶层块。 |
| 两格内的 DOM 文字选区 `CellLeft:2 → CellRight:4`，两轮 | H2 | 只有左格内的正文变成 H2。右格内正文和表格结构保持。 |
| 两格有选中标记，焦点在整块选择的隐藏输入中，两轮 | H2 | 两格内正文均变成 H2，归属各自单元格。一次撤销可回原局部类型，重做后保存，刷新仍读回两格 H2。 |

表格场景先确认真实选区。反向拖动在本样本里进入了整格模式，记录两格的选中标记和焦点后才执行转换。文字 Range 与双格选择需要各自留证。刷新前后浏览器 DOM 中的数字 ID 可能变化，跨会话用文字、类型、行列位置和父级核对。

### REQ-S12-08 历史、保存与入口核验

每次运行记录操作前的端点或整块选中对象。执行后核对目标块及护栏、引用层级、空段、格式、编号、父级与焦点。一次撤销恢复原结构，一次重做恢复转换结果。普通边界记录文字偏移，整格和整块选择记录选中对象。跨刷新通过可见结构、正文与容器位置核对。

菜单路径记录真实选区工具栏和二级入口。测试同步源时，菜单文字出现后仍存在动画中的短暂点击空档。连续读取实际点击命中，确认可点击再执行。正向成功后和反向一致地形成同步源容器，历史均可往返。较早的未命中操作记为前置探查。

## 4. 复跑样本

样本独立建在飞书空白文档，正文的字符偏移从 0 计。先用可见菜单、标题快捷键和列表编辑建立结构，也可用富文本粘贴后先核对层级与起号。

| 样本 | 正文与前置 | 检查点 |
| --- | --- | --- |
| A 混合目标矩阵 | `LGuard` 正文、`A1aaa` H1（`1` 加粗）、`B2bbb` 正文、起号 7 的 `C3ccc` 有序项、它的无序子项 `Kid4`、同级有序项 `E5eee`、共同引用里的 `Q6quote` 与 `Q7quote`、`RGuard` 正文。主范围 `A1aaa:1 ↔ E5eee:3`。 | 17 目标正反向、普通和引用的零偏移、跨引用、正文整块全选。 |
| B 引用子集 | `LGuard`、同一引用内三段 `QFirst`、`QMiddle`、`QLast`、`RGuard`。范围 `QFirst:2 ↔ QMiddle:4`。 | 两方向部分解包，前两段转无序项时原引用保持。 |
| C 空行与软换行 | `LGuard`、`First`（`s` 加粗）、空段、同一块内 `Word` 加 Shift+Enter 加 `Soft`、起号 12 的 `NumTail`、`RGuard`、末空段。 | 鼠标两方向、Shift+↓ 扩选、两级全选，核对转换、软换行与尾空段。 |
| D 折叠与表格 | `LGuard`、H1 `FoldHead`、H2 `ChildHead`、正文 `ChildText`、H1 `NextHead`、正文 `Outside`、`RGuard`。折叠 `FoldHead`。表格用例在 `RGuard` 后插入 2×3 表格。 | 只选折叠标题、跨折叠到 0 和到 2、表格外到内、跨格文字与整格、保存刷新。 |
