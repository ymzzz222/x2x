## 前台复核

以下实测开始前观察了原类型、引用容器和实际选择。`T` 为正文，`O` 为有序项，`B` 为无序项，`Q` 为引用内正文。受影响的代表场景再次撤销和重做，正文及实际结构可往返。

| 场景 | 飞书预期 | x2x 生产实际 |
| --- | --- | --- |
| `TQ → H2`，富文本导入引用，正反各一轮 | 引用内段落成为 H2，保持引用归属。 | 两块都成为 H2。原引用容器脱落，文字和护栏保持。 |
| `TQ → H2`，通过工具栏创建引用 | 保留引用归属。 | 两块都成为 H2，引用容器保留。和富文本导入前置得到不同结果。 |
| `TOQ`、`QOT → 引用` | 外部连续块进入新增引用，原引用保留独立容器。 | `TOQ` 保留两个容器。`QOT` 三块被放进同一引用。用工具栏建原引用复测 `QOT`，仍合成一组。 |
| 拖选从外部正文到共同引用的第一段，再转 H2 | 实际范围扩入整段引用，两段标题仍归属原引用。 | 选区标记停在第一段内部。执行后两段都变成 H2，原引用容器脱落。 |
| 共同引用的三段中半选前两段，再点引用 | 前两段解包，末段留在原引用。 | 与参考一致，第一段的粗体仍在。 |
| `OBO`、`BOO → 引用` | `OBO` 的两个有序项分开，各从 1 开始。`BOO` 的连续有序项编号 1、2。 | `OBO` 得到两个起号为 1 的列表。将 `BOO` 建为一个真正的两项连续列表后，整个列表一起进入引用，起号 1，列表仍含两个连续项。若富文本原本含两个独立列表，则分别保留起号 1。 |
| `TO → 有序`，先用快捷键建立现有有序项 | 连续两项编号 1、2。 | 结果为 1、2，撤销、重做准确。通过粘贴建立的独立列表可保留自身起号。 |
| `TQ → 有序`，富文本导入引用 | 引用内外各有一项，分别从 1 起号。 | 外层编号 1、2。第 2 项里，引用文字上方多出一行空段。撤销移除多出的一行，重做重新出现。 |
| 例 A 的混合五块转 H2、引用、高亮 | 标题序列为无编号、无编号、1、2、3。引用或高亮包成一个容器。 | 转 H2 后子项仍归父项，五块标题均未显示编号。转引用得到一个新增引用，保留原显式起号 7、8。转高亮出现三个容器。 |
| 普通下一标题偏移 0、折叠标题跨隐藏后代 | 下一标题排除。跨折叠区时隐藏后代参与转换。 | 反向拖选后，两条边界均符合。折叠后代转无序，下一标题保持 H1。 |
| 两级全选转 H2，含软换行、末尾空段 | 最后空段也转换，软换行保留，原有序项成为编号标题。 | 五段均为 H2，末空段和软换行正确。原有序项转成无编号 H2。 |
| 反向选择 12 块混合来源，转 H2 | 顺序、文字和两个已有引用归属保持。 | 12 块都成为 H2，两处原引用归属丢失；前后护栏、文字顺序和历史保持。 |

自动化另确认三处边界。拖到引用第一段偏移 0 时，x2x 只选择及转换外部正文。拖到 `E5eee:0` 后，该项保持有序，但编号仍为 8，飞书为 1。连续两次 Shift+↓ 只选中首段余下文字，转 H9 后中间空段和软换行段保持原类型。引用内半选两段转无序、折叠父标题内结束以及跨过下一标题的补跑通过。
