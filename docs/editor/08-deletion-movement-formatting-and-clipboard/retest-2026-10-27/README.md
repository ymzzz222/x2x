## 4 全文读取的证据边界

10个普通段合计500001个ASCII正文字符，剪贴板包含9个LF，共500010个UTF-16单位。
原生全选复制得到10行，实际SHA-256与生成载荷相同。
两轮均完成Undo清空、Redo恢复及再次Undo清空。
为刷新读回，又真实Redo回同一载荷，并再次复制核对。
两次真实刷新产生不同timeOrigin，全文复制仍为500010单位、10行、同一SHA。
分别见 `browser-refresh-1.json` 与 `browser-refresh-2.json`。
虚拟化页面只渲染当前视口，不能用可见DOM块数或可见字符数宣布全文完整。
DOM快照只描述已渲染块；全文计数与完整性来自实际复制的公共clipboardData。
复制监听覆盖docx-selection-hidden-textarea，原按键监听仅覆盖root-block。
因此不宣称所有结构选区按键均有完整事件记录。
早期控制台结果截断及复用标记风险已记录，后续采样使用逐次唯一标记。
