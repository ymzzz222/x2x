# 少年中国史 — 全书大纲

> 10 卷，从上古到近现代，编年连贯，小朋友顺着读。
> 每一卷目录见各卷首页，每一节独立成文，均可互相引用。

## 叙事框架

### 核心设定

- **时间**：公元 3000 年，人类发明了"时光机"
- **主角**：咩咩，一个好奇心旺盛的小女孩
- **规则**：咩咩通过时光隧道回到过去，她不会随着时间的流逝长大，始终保持小孩子的模样
- **视角**：第一人称，咩咩亲眼见证、亲身参与、亲口讲述
- **基调**：不是冰冷的历史课本，而是一个小朋友的冒险日记

### 互动规则：「听得见、聊得上、改不了」

咩咩在时光旅行中可以和任何人对话——问路、提问、聊天、追问。但有一条铁律：

> **历史人物只向咩咩"输出"，不会因为她的存在而改变任何行为。**

具体表现：
- 咩咩可以问元谋人"你为什么要用这块石头？"，对方会回答（或用手势回应），但该打猎还是打猎，该搬家还是搬家
- 咩咩可以和北京人围坐在篝火旁聊天，但火该灭还是会灭，该续还是会续
- 咩咩可以问山顶洞人"你做这个项链干什么？"，对方会笑一笑告诉她，但该怎么做还是怎么做
- **她像一个"透明的客人"**——被看见、被回应、但不影响任何事

这带来三个叙事优势：
1. **趣味性**：对话比旁观生动得多，小朋友跟着咩咩一起"采访"古人
2. **知识传递**：通过问答自然引出知识点，而不是生硬地"讲课"
3. **历史敬畏**：改不了历史——每一次冒险都提醒小朋友，历史有它自己的逻辑

### 叙事手法

| 层次 | 说明 | 示例 |
|------|------|------|
| **主线叙事** | 咩咩的第一人称讲述，用孩子的语言描述所见所闻 | "我摸了一下那块石头，居然是热的！原来北京人刚用完火" |
| **对话互动** | 咩咩主动和古人对话，古人用自己的方式回应（语言/手势/表情） | "我问她：'你做这个干什么？'她笑了笑，把项链往脖子上比了比" |
| **知识嵌入** | 遇到不懂的事物时，时光机的手环会振动，投射出"知识卡片" | 【知识卡】元谋人距今约 170 万年，是中国境内已知最早的人类 |
| **古今对比** | 咩咩经常拿过去和 3000 年的生活做对比 | "他们没有冰箱，但聪明极了——挖个地窖，冬天存冰，夏天就能喝到凉水" |
| **人文关怀** | 不只讲"发生了什么"，还讲"人是怎么想的" | 山顶洞人为什么要做项链？——他们不只是活着，他们开始想"美"这件事了 |
| **地域特色** | 每到一个地方，描述当地的气候、地貌、动植物 | "云南那时候比现在还热，到处是密林，大象在河边喝水" |
| **习俗溯源** | 遇到今天还存在的事物，追溯它的起源 | "你知道过年为什么要放鞭炮吗？这要从远古人驱赶野兽说起……" |

### 章节结构模板

每一节遵循统一结构（可根据内容灵活调整）：

```
## 开篇 · 时光机启动
    咩咩收到任务 / 好奇心触发 / 时光隧道开启

## 第一幕 · 初到远古
    环境描写（气候、地貌、动植物）/ 第一印象

## 第二幕 · 遇见古人
    观察古人类的生活 / 互动或旁观 / 发现关键文物或遗迹

## 第三幕 · 关键时刻
    本节的核心历史事件或考古发现

## 第四幕 · 人文思考
    这件事意味着什么？和今天有什么联系？

## 收尾 · 时光机回程
    咩咩的感想 / 留下悬念引向下一节
```

### 知识卡片系统

咩咩手腕上的"时光手环"会在关键时刻投射知识卡片，用于嵌入考古事实、地理知识、科学原理：

- 【考古实证】——出土文物、遗址发现
- 【地理百科】——远古地貌、气候变化
- 【科学解密】——体质特征、工具原理
- 【习俗溯源】——今天还在用的东西的远古起源
- 【古今对比】——过去 vs 3000 年的差异

## 第一卷：远古・炎黄尧舜（史前 — 约前 2070）

**写法基调**：把考古发现的器物、生活场景写成少年探险日常。

### 主要内容

- **远古人类**
  - 元谋人（约 170 万年前，中国境内已知最早人类）
  - 北京人（约 70 万—20 万年前，会使用火）
  - 山顶洞人（约 3 万年前，会缝制衣物、佩戴装饰品）
- **农耕文明的曙光**
  - 河姆渡文化（长江流域，水稻种植、干栏式建筑）
  - 半坡文化（黄河流域，粟米种植、半地穴式房屋）
  - 仰韶文化彩陶、大汶口文化
- **炎黄联盟与涿鹿之战**
  - 黄帝与炎帝阪泉之战后结盟
  - 涿鹿之战：炎黄联盟击败蚩尤（据《史记・五帝本纪》）
  - 华夏族的形成
- **尧舜禹与禅让制**
  - 尧设诽谤木、定历法
  - 舜耕历山、渔雷泽
  - 大禹治水：疏导法，三过家门而不入（正史记载）
- **禅让制的终结**
  - 禹传位于益，启夺位建夏
  - 世袭制取代禅让制——中国历史上第一个王朝诞生

  - 南明抗清、郑成功收复台湾（1662 年）
- **康乾盛世**
  - 康熙：平三藩、收台湾、抗击沙俄（雅克萨之战）、签订《尼布楚条约》
  - 雍正：设军机处、摊丁入亩、改土归流
  - 乾隆：十全武功、编纂《四库全书》
  - 人口突破三亿
- **盛世之下的隐忧**
  - 闭关锁国政策
  - 文字狱
  - 白莲教起义
- **近代屈辱与抗争**
  - 鸦片战争（1840—1842）与《南京条约》
  - 太平天国运动（1851—1864）
  - 第二次鸦片战争（1856—1860）、火烧圆明园
  - 洋务运动：自强求富、创办近代工业
  - 甲午战争（1894—1895）与《马关条约》
  - 戊戌变法（1898 年）——百日维新
  - 八国联军侵华（1900 年）与《辛丑条约》
- **辛亥革命与民国**
  - 孙中山与同盟会
  - 辛亥革命（1911 年）——推翻帝制
  - 中华民国建立（1912 年）
  - 袁世凯窃国与复辟
  - 军阀混战

  - 中国共产党成立（1921 年）
