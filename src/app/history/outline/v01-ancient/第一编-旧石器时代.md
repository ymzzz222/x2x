## 第 01 节 · 中国最早的人类

> 时间：约 170 万 — 115 万年前
> 地点：云南元谋 → 陕西蓝田

### 一、元谋人（约 170 万年前）

- 1965 年，云南元谋上那蚌村发现两颗人类门齿化石
- 同一地层出土打制石器和炭屑
- 属于直立人阶段，是中国境内已知最早的人类化石
- 学界对炭屑是否为人工用火证据存在争议
- 当地为热带森林环境，大象、犀牛活动频繁

### 二、蓝田人（约 115 万年前）

- 1963—1964 年，陕西蓝田公王岭和陈家窝发现头盖骨及下颌骨化石
- 脑容量约 780 毫升，比元谋人有所增加
- 出土打制石器，已出现初步的选材意识（偏好燧石）
- 当地为稀树草原环境，灞河两岸野马、野鹿成群
- 已具备基本的狩猎能力，生活方式从纯采集向采集+狩猎过渡

### 三、旧石器时代早期要点

| 项目 | 元谋人 | 蓝田人 |
|------|--------|--------|
| 时间 | 约 170 万年前 | 约 115 万年前 |
| 地点 | 云南元谋 | 陕西蓝田 |
| 化石 | 两颗门齿 | 头盖骨、下颌骨 |
| 脑容量 | 约 700 毫升 | 约 780 毫升 |
| 石器 | 简单打制 | 有选材意识 |
| 环境 | 热带森林 | 稀树草原 |
| 生活方式 | 采集为主 | 采集 + 狩猎 |

## 第 02 节 · 北京人的火光

> 时间：约 70 万 — 20 万年前
> 地点：北京房山周口店龙骨山

### 一、遗址发现

- 1929 年，裴文中发现第一个完整的北京人头盖骨化石
- 遗址共出土 40 多个个体的化石、10 万多件石器、大量动物化石
- 1941 年，北京人化石在转移过程中失踪，至今下落不明——考古史最大悬案

### 二、体质特征

- 属于直立人阶段
- 脑容量约 1088 毫升（现代人约 1400 毫升）
- 前额低平、眉骨粗壮、颧骨高、嘴巴前伸、无下巴
- 平均身高约 1.56 米，肌肉发达
- 头骨很厚，牙齿磨损严重（饮食粗糙所致）

### 三、用火证据

- 遗址发现厚达 6 米的灰烬层，证明长期、持续用火
- 灰烬中有烧裂的石块、烧焦的骨骼和朴树籽
- 当时应为保存天然火种（如雷击引发的火），尚不会人工取火
- 火的用途：取暖、熟食、照明、防御野兽

### 四、群居生活

- 二三十人为一个群体，居住在洞穴中
- 已有初步的分工协作：围猎大型动物时分组配合
- 洞穴选址有讲究：朝南避风、靠近水源
- 周口店一带为温带森林与草原交界，冬天寒冷，洞穴是关键庇护所

### 五、狩猎方式

- 无弓箭，靠团队合作和耐力追猎
- 主要猎物：肿骨鹿、野马等
- 战术：分组驱赶 + 侧翼埋伏，将猎物赶入死角
- 已具备基本的群体协调能力

## 第 03 节 · 智者的黎明

> 时间：约 3 万年前
> 地点：北京房山周口店山顶洞

### 一、山顶洞人

- 属于晚期智人，与现代人同种
- 脑容量约 1300—1500 毫升，和现代人基本相同
- 外貌已接近现代人：前额饱满、下巴明显、眉骨平缓
- 已具备语言能力，能进行完整的语言交流

### 二、骨针与缝纫

- 出土一枚骨针，长 82 毫米，针眼直径约 3 毫米
- 用动物骨头磨制而成，制作精细
- 说明已能缝制兽皮衣服——御寒能力飞跃
- 时代背景：冰河时期，华北冬天零下二三十度，无衣物难以存活

### 三、装饰品

- 出土 141 枚装饰品：穿孔贝壳、钻孔兽牙、刻纹骨管
- 贝壳来自数百公里外的海边——已存在远距离交换网络
- 部分装饰品涂有红色赤铁矿粉
- 装饰品可能与身份地位有关——社会分化萌芽

### 四、丧葬习俗

- 死者身上撒红色赤铁矿粉——中国最早的丧葬习俗
- 红色象征血液和生命，暗示对死亡的思考
- 是人类最早的精神信仰萌芽

### 五、火的管理

- 洞穴内有专门的火塘，用石头围起
- 有专人负责看管火种——可能是最早的职业分工
- 已能人工取火（钻木或击石）的可能性较大

### 六、旧石器时代晚期要点

| 项目 | 山顶洞人 |
|------|----------|
| 时间 | 约 3 万年前 |
| 地点 | 北京周口店山顶洞 |
| 种属 | 晚期智人（与现代人同种） |
| 脑容量 | 1300—1500 毫升 |
| 语言 | 有完整语言能力 |
| 工具 | 精细石器 + 骨器（骨针） |
| 衣着 | 缝制兽皮衣服 |
| 装饰 | 贝壳项链、兽牙饰品 |
| 丧葬 | 撒赤铁矿粉 |
| 交换 | 远距离物品交换网络 |
